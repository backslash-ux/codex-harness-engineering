# Security

## Supported version

Security fixes target the latest tagged release and the current `main` branch.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for this repository and include:

- the affected command or workflow;
- the repository conditions required to reproduce it;
- the potential filesystem, credential, provider, or approval-boundary impact;
- a minimal reproduction when safe.

This project does not operate a hosted service, collect telemetry, or require
credentials. Reports about Codex itself or third-party providers should be sent
to the relevant vendor.
